# TaskNova

TaskNova is a cross-platform Flutter application for managing tasks and subtasks, designed to boost productivity with modern features like AI-powered suggestions, speech-to-text input, and Google AdMob integration.

## Features

- **Task & Subtask Management:** Create, edit, and organize tasks and subtasks.
- **AI Suggestions:** Get smart suggestions and motivational quotes to stay productive.
- **Speech-to-Text:** Add tasks quickly using your voice.
- **AdMob Integration:** Monetize your app with Google AdMob banner ads.
- **Light & Dark Themes:** Switch between beautiful light and dark modes.
- **Animated UI:** Enjoy a responsive and visually appealing interface.

## Getting Started

To run TaskNova locally:

1. **Clone the repository:**
   ```sh
   git clone https://github.com/yourusername/tasknova_flutter.git
   cd tasknova_flutter
   ```

2. **Install dependencies:**
   ```sh
   flutter pub get
   ```

3. **Run the app:**
   ```sh
   flutter run
   ```
